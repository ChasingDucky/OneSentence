# One Sentence Today - 项目完成总结

## 项目概述

One Sentence Today 是一款基于匿名、随机配对的社交应用。用户每天可以发布一句话，系统会随机将这句话匿名发送给另一位用户，同时用户也会收到来自其他人的匿名句子。

## 如何运行

### 使用 Docker（推荐）
```bash
# 克隆项目
git clone <repository-url>
cd OneSentence

# 启动所有服务
docker-compose up -d

# 初始化数据库
docker-compose exec backend npm run db:migrate

# 访问应用
# 前端: http://localhost
# 后端: http://localhost:5000
```

### 本地开发
```bash
# 后端
cd backend
npm install
cp .env.example .env
npm run db:migrate
npm run dev

# 前端（新终端）
cd frontend
npm install
npm run dev
```
